About this project

PlantDoc is an end-to-end deep-learning application that identifies crop leaf diseases from smartphone images. It was built as an applied ML portfolio project demonstrating the full pipeline — data, modelling, evaluation, deployment, and explainability.

The Model

The classifier is a MobileNetV2 convolutional neural network pre-trained on ImageNet and fine-tuned on the PlantVillage dataset (54,306 images across 38 classes covering 14 crop species). Training uses a two-phase schedule: first the classifier head is trained with the backbone frozen; then the top 30 layers of the backbone are unfrozen and fine-tuned with a low learning rate.

Explainability

For every prediction, a Grad-CAM heatmap (Selvaraju et al., 2017) shows which regions of the leaf most influenced the model's decision. This is important in agriculture, where users need to trust and verify AI recommendations before acting on them.

Tech stack

  • TensorFlow 2 · Keras
  • Flask 3 for the web server & REST API
  • OpenCV for Grad-CAM overlay rendering
  • Pillow for image I/O
  • Vanilla HTML / CSS / JavaScript (no framework)
  • Docker for containerised deployment

Limitations

  • Trained on lab-style PlantVillage images with plain backgrounds. Field photos with busy backgrounds may perform worse.
  • Covers 38 specific classes only; other diseases will be misclassified as the closest match in the training set.
  • Treatment advice is general guidance, not a substitute for agronomist consultation.
